How this site is built

ukdoshi.com is small, but it's a real system: an Angular site and a Python API running on AWS serverless, with passwordless sign-in, a private members' area, and a pipeline that tests every change on a staging copy before it goes live. I designed and built it with Claude Code.

Decisions and trade-offs

Serverless, pay for what's used
No servers to patch or keep running, and a quiet personal site costs very little.
One address for the site and its API
CloudFront sends /api calls to the API, so the browser never talks to a second domain.
No passwords
Google or a one-time email code, so there are no passwords to forget, reuse or leak.
Signing in isn't access
The API checks every token itself, then an approved list decides who sees the Inner Circle.
No cloud keys stored anywhere
GitHub logs in to AWS with short-lived tokens (OIDC), limited to this repository's branches.
Infrastructure as code
The AWS setup is Python (AWS CDK), so staging and live are built from one definition.
Staging before live
Every change runs on a full, separate copy of the site first, where it can be shared and tested.
Private by default
No analytics or trackers, and personal API answers are never kept in the browser's cache.
